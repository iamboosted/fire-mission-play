# Fire Mission — play in your browser

A co-op artillery game. This repository only holds the built game that GitHub Pages serves; there is
no server and nothing to install.

**Play:** open the GitHub Pages address of this repository in Chrome, Edge or Firefox.

**Co-op:** one player presses **Host co-op** and sends the invite code to a friend privately. The
friend presses **Join with code**, pastes it and sends back the reply code. Nobody can join a battle
unless the host pastes their reply. Game traffic goes directly between the two browsers, encrypted.

Third-party assets and their licences are listed in [CREDITS.md](CREDITS.md).
